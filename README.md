# chatpak

Generator gambar pribadi (PWA). Lihat `docs/TECH-DESIGN.md`.

```
npm install
cp .env.local.example .env.local   # biarkan IMAGE_API_KEY kosong = mode demo
npm run dev
```

Pasang API: isi `IMAGE_API_KEY` (dan `ACCESS_CODE` untuk produksi) di `.env.local` atau env Vercel. Tidak ada perubahan kode.
